================================================================
SECTION 13: WHAT TO CHECK ACROSS ALL TESTS
================================================================

When running these tests in your IDE, track these things:

1. COMPILE ERRORS
   - Does the error message tell you WHAT went wrong?
   - Does it tell you WHERE (line number, variable name)?
   - Is it clear enough that a beginner would understand it?

2. VALID PROGRAM OUTPUT
   - Is the output exactly what you expected?
   - Are numbers printed as numbers, strings as strings?
   - Are multiple bol statements on separate lines?

3. CRASH VS GRACEFUL ERROR
   - Invalid programs should give compile errors, NOT crash the IDE
   - The output panel should always show something — never blank on error

4. EDGE CASES
   - Empty program: should not crash
   - Zero value: should print 0, not blank
   - Empty string: should print blank, not undefined or null

5. CONSISTENCY
   - Same program run twice should give same output
   - Error messages for the same kind of error should be consistent
